StudyHuman Control Panel

Edit your website — no code needed

Everything on the StudyHuman homepage — text, prices, services, helpers, FAQs — comes from one file: content.json. Edit it here in plain forms, preview your changes, then publish in three steps.

First, load the current content

If this panel was opened from the live website, the content loads automatically. If it didn't (for example you opened the file straight from your computer), pick the content.json file here instead.

How publishing works

Fastest is the one-click Publish card right below — it commits straight to GitHub once you've saved a token. Or publish by hand with a quick download-and-paste:

1

DownloadMake your edits below, then press the big “Download updated content.json” button (bottom of the screen).

2

Open the file in GitHubOpen docs/content.json in the repo →
Select everything in the editor and paste your downloaded file's contents over it.

3

CommitPress GitHub's green “Commit changes…” button. That's it.

⏱ Your changes go live about 1 minute after committing — refresh the website to see them. Nothing here changes the live site until you commit.

Publish to the live site — one click

Save a GitHub token once on this device, then this button commits your edited content.json straight to GitHub — no download, no paste. (The Download button at the bottom of the screen still works as a manual fallback.)

No token saved.

The token is used only to commit docs/content.json to your GitHub repo (collinsmwinyi-sys/bridge-human-academics) via api.github.com. It is stored only in this browser — never in content.json, the preview, or any download — and you can revoke it anytime in GitHub → Settings → Developer settings → Personal access tokens.
